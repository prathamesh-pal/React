## Tech Stack

- React
- JavaScript (ES6+)
- CSS

## Getting Started

Each project is self-contained with its own `package.json`. To run one:

```bash
cd "Day1/gradient-generator"
npm install
npm run dev
```

## About

Built as part of a self-directed React learning practice — one small project at a time to reinforce core concepts (state, props, hooks, API calls, and UI patterns) through hands-on building.
